# Definition of Done

A change is done only when:

- Every acceptance criterion is mapped to implemented behavior and evidence.
- Relevant tests, type checks, lint, and builds have run with recorded outcomes.
- Error paths, accessibility, security, compatibility, and migration effects were considered where applicable.
- Documentation and configuration match the delivered behavior.
- The final diff contains no unrelated edits, temporary diagnostics, generated junk, or secrets.
- Remaining risks and unverified behavior are stated plainly.

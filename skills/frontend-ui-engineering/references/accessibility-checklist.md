# Accessibility Checklist

- Use semantic elements and correct accessible names before ARIA workarounds.
- Support keyboard operation, visible focus, logical order, and escape behavior.
- Preserve labels, descriptions, errors, status announcements, and focus after dynamic updates.
- Check contrast, zoom, reflow, reduced motion, pointer alternatives, and touch target sizing.
- Test representative flows with keyboard and browser accessibility tooling.
- Record the observed behavior and the WCAG success criterion when reporting a defect.

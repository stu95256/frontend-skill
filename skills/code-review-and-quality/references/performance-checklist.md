# Performance Review Checklist

- Establish the user-visible or measured performance budget before optimizing.
- Look for unnecessary renders, repeated work, request waterfalls, oversized bundles, and unbounded collections.
- Verify memoization and caching keys, invalidation, ownership, and memory growth.
- Distinguish startup, interaction, rendering, network, and server costs.
- Require measurements before and after any claimed improvement.
- Reject micro-optimizations that increase complexity without material evidence.
